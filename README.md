## 🚀 Installation

```bash
git clone https://github.com/RishabhDimri/expense-tracker-frontend.git
cd expense-tracker-frontend
npm install
```

## 💻 Usage

```bash
npm run dev
```

## ✨ Features

- ✅ Secure user authentication
- ✅ JWT-based authentication
- ✅ Responsive financial dashboard
- ✅ Income and expense tracking
- ✅ Create, edit, and delete transactions
- ✅ Transaction history
- ✅ Transaction analysis and financial insights
- ✅ Category management
- ✅ Custom transaction categories
- ✅ Monthly budget management
- ✅ Budget monitoring
- ✅ Monthly financial summaries
- ✅ PDF financial report access
- ✅ Light and dark theme support
- ✅ Responsive design
- ✅ Editorial financial dashboard UI
- ✅ Retro-inspired UI components
- ✅ Interactive forms
- ✅ Protected application routes
- ✅ API integration
- ✅ Loading and error states
- ✅ Mobile-friendly interface
